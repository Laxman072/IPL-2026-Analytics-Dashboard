# 🏏 IPL 2026 Analysis Dashboard | Power BI

## 📌 Project Overview

The **IPL 2026 Analysis Dashboard** is an interactive Power BI project designed to analyze the complete IPL 2026 season using match-level and ball-by-ball data.

The dashboard transforms raw cricket data into meaningful insights through interactive visualizations, KPI cards, player analytics, and tournament statistics. It enables users to explore team performance, batting records, bowling achievements, and individual player profiles in a user-friendly interface.

---

# 🎯 Project Objectives

* Analyze overall IPL 2026 tournament performance.
* Compare batting and bowling statistics.
* Explore player-level performance.
* Identify tournament leaders and key milestones.
* Create an interactive dashboard suitable for business reporting and sports analytics.
